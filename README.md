# Evidence Literature Review Skills

完整可安裝版本位於 **[release/v0.6](https://github.com/showtime201005/evidence-literature-review-skills/tree/release/v0.6)**。

```bash
git clone --branch release/v0.6 https://github.com/showtime201005/evidence-literature-review-skills.git
cd evidence-literature-review-skills
```

請將 repo 交給 OpenCode，要求它讀取 `INSTALL.md`，將五個 skills 安裝至指定研究專案並執行安裝檢查。

公開版本包含五個獨立 skills、完整 runtime、安裝腳本、通用框架指引與合成範例。歷史執行紀錄、內部路徑與部署設定不包含在發行分支。

原生工具整合已測 OpenCode 1.19.3、DeepAgents 0.7.0；真實模型 endpoint 的研究品質須另行驗收。分析範圍為提供的 Markdown，並非外部文獻資料庫全網搜尋。
