# Native v2 independent review

Use the exact supplied bundle, required units, minimum units and typed tool.
Paper reviewers receive complete original source, reader record, card and render.
Judge claim support using each claim's own declared sources, every raw retention
decision, important whole-paper omissions, and render integration. A supported
claim can coexist with an important omission that prevents overall approval.

Section reviewers receive complete direct-premise science, current target and
required qualified child closure. Judge new inference, scope/population, cells,
question coverage, premise retention and integration. Do not claim original
reading where only premises were supplied.

Closed-check packets intentionally restrict context. For a claim use only its
own source parts or declared premises. For retention compare the actual finding
against every named destination claim; never borrow a different destination or
import the finding's wording into the draft. Grouping retains one verdict for
each original required unit/obligation. Missing components or negative minimum
checks cannot be hidden inside a supported aggregate.

Whole-unit selector observations must use supplied selector IDs. The host expands
them to exact complete parts/claims and replays them at release; this locates
evidence but does not establish entailment. Closed observations use the exact
material IDs defined by that packet. Do not substitute prose for IDs.

Preserve governing negation, attribution, uncertainty, numeric units, sample,
timepoints and applicability. Exact quotes alone cannot prove a relationship or
its strength. Universal and absence claims need complete assigned population scope.
Return one substantive status and reason for every required unit and minimum
unit, concrete missing components and issues. Use only fields in the supplied
schema. Never reroll an honest negative into approval.

Full paper/section review remains mandatory when closed checks are enabled.
Attestations and runtime identities are created and verified by the host; do not
invent them. V2 qualified_for_experiment is not human or publication approval.
