# 範例信任狀態

這些檔案僅示範使用者輸入，未附任何預設答案或已通過的模型 verdict。

review-spec.json 交給 research-request；report.md 與 gaps.json 交給 augmentation-plan。
請替換研究問題、搜尋同義詞與缺口條件；所有數值、缺口狀態和證據映射，均須閱讀實際來源後產生。

輸出契約、每個欄位及可讀交付見 references/research-modes.md。若原報告沒有占位符，可使用原文中不重複的完整 anchor；重複 anchor 必須提供 Unicode start_char。沒有原文證據時保留缺口，不套用示例值。
