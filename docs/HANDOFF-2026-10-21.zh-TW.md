**目前尚未完成「100 篇 Markdown、每篇約 10 頁、90 分鐘內完整交付」驗收。新版 native v2 最近兩篇 cold run 亦未完成交付。** 本次交接文件沒有啟動新的模型請求；文件與 skills 的 GitHub 打包／上傳，應以主代理最後的實際操作紀錄確認。

## 1. 使用者需求與驗收邊界

- 輸入只需 Markdown；目前不要求 PDF 轉換，也不執行外部文獻搜尋。研究結論限於提供的 corpus。
- 正式規模是 100 篇、每篇約 10 頁；頁數須以實際字數／tokens 與表格結構說明，不能只靠「10 頁」標籤。
- 正式時間目標是 **90 分鐘**，包含實際委派、模型等待、限流等待、重試、修訂、查核及交付。環境／資料準備的排除範圍須事先記錄；正式處理不能帶入已接受的分析或查核快取。
- Windows 與 Ubuntu 22.04 均須可安裝執行；需要 Python 3.11+。
- 使用 `qwen/qwen3.8-27b`，透過 OpenRouter；單次完整請求上限 200,000 tokens，供應商較低限制仍須遵守。上限包含歷史、工具 schema、輸出預留與安全餘量。
- 需要真 DeepAgents coordinator→`task`→隔離子代理的委派；host 直接平行呼叫模型不能冒充這項能力。
- 最終成果至少有主報告、每篇精簡證據卡、比較表、可追溯引用、完整原始 extraction 與查核／修訂紀錄。
- 另需獨立繁體中文 HTML 技術介紹，說明五 skills 用途、協定、輸入／輸出、獨立執行、架構、特殊設計、實測與限制。HTML 須依最後凍結版本更新，不能宣稱尚未完成的驗收。

### 不可混淆的版本

- 目前 typed native：DeepAgents **0.7.15**，入口 `native_task.py`／`native_review.py`。
- `native_review.py` 預設 `--review-protocol v1`；新版 combined review 須明確用 `--review-protocol v2`。
- v2 是實驗性驗證協定；即使 delivery 完成也保持 `publication_verified=false`、`quality_validated=false`。
- 舊 deterministic CLI 套件版本為 0.6.0，文件含 v0.4/v0.5 artifacts；`ComparisonSet v2` 不等於上述 native review v2。
- 舊 `harness_runner.py --harness deepagents` 走 `deepagents070.py`，精確要求 **0.7.0**。不能拿它啟動目前 0.7.15 typed 流程。

可攜介面參考為本文件、`implementation-guide.zh-TW.html` 與 [JSON Schema 快照](evidence/skill-interface-schemas-20261021.json)。請一併讀 [schema 快照狀態](evidence/schema-snapshot-status.json)，確認與最新 source 的差異。本機另有 `repo/reports/skill-interface-inventory-20261021.md` 的歷史盤點，未放入本次 package；其中 installer 差異後來已依本交接第 7 節修正，後加的 strict candidate 亦須讀目前原始碼，不可把歷史盤點當最新介面。

## 10. 安裝與重現命令

### 本輪 latest cold2 配置的重現範本

```text
python -X utf8 /ABS/PROJECT/skills/literature-review/scripts/native_review.py --sources /ABS/PAPERS --questions /ABS/questions.json --out /ABS/new-cold-run --skills-root /ABS/PROJECT/skills --tokenizer /ABS/PROJECT/qwen-tokenizer.json --review-protocol v2 --review-observations whole-unit --closed-checks --workers 16 --group-size 2 --active-token-limit 1000000 --deadline 1200 --reader-reasoning off --writer-reasoning off --reviewer-reasoning off --reviewer-max-output-tokens 16384
```

精確重現舊 run 應使用其 invocation 綁定的 frozen installed snapshot；目前 canonical 有後續 installer／strict 變更，重新安裝後要標為新版本。原外部 launcher 從 task 開始採 1200 秒總計時，再將剩餘約 1194.985 秒傳入 CLI；直接使用 `--deadline 1200` 不等於包含 import/setup 的外部 1200 秒。

正式百篇目標可設定 `--deadline 5400`，但仍須外部 caller 從任務下達至 process exit 全程計時並把剩餘時間傳入；該參數不是完成承諾。

來源是目錄第一層 1–100 個 UTF-8 `.md`／`.markdown`，filename stem 含大小寫需唯一；questions 為 array 或 `{questions:[...]}`，含唯一 id 與明確研究問題。沒有 PDF、recursive sources、native CLI resume、`--model`／`--rpm`／`--tpm` 或 strict CLI 選項。

Input 必須是公開且經實際 builder/validator 檢查的 packet：reader=`scientific-source/1`；writer/comparer=`review-draft-packet/1`；單任務 verifier=`native-proof-input/1`，且只准無 dependencies 的 source node。v2 paper／section／closed workers 為 Python API＋完整 native_review 接線，目前不能謊稱各自另有單任務 shell CLI。
